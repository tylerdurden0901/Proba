# Документация решения

## 1. Функциональные требования

В ходе общения с заказчиком выявлены подробные требования к разрабатываемому решению:

• в качестве предметной области и исходных данных выступает Файловая Система Преподавателя из Лабораторной работы №3;

• реализация возможности вывода имени и группы студентов, чье имя не соответствует формату "ФамилияИО", сразу из нескольких групп с возможностью использования ключей для сортировки по ФИО/номеру группы/году группы и для обратного порядка вывода результатов;

• реализация возможности вывода списка группы, упорядоченного по количеству попыток сдачи указанного пользователем теста (по умолчанию по убыванию), с возможностью обратного порядка вывода;

• реализация возможности вывода номеров пропущенных занятий по каждому предмету у студента, имя которого, как и название предмета, может быть введено не полностью, а лишь несколькими буквами;

• реализация возможности вывода списка студентов с учетом их среднего балла успеваемости (по убыванию) за заданный пользователем временной интервал.

## 2. Разбор команд и примеры их использования

| Команда | Данные для выполнения команды | Выходные данные |
|---------|-------------------------------|-----------------|
| вывод студентов с нестандартной записью имени (1) | номера интересующих групп | имя студента, его группа |
| список по количеству попыток сдачи теста (2) | номер группы, название теста в полной форме (предмет/tests/TEST-*номер*) | имя студента, количество попыток сдачи теста |
| вывод пропусков студентов (3) | имя студента | для каждого предмета: имя студента, его группа, номера пропущенных занятий |
| вывод студентов по среднему баллу (4) | диапазон лет, по которым нужны баллы | группа студента, его имя, средний балл успеваемости |

В команде (1) может быть как одна, так и несколько групп. Ключи: `-f` — по алфавитному порядку, `-g` — по номеру группы, `-y` — по году группы, `-r` — в обратном порядке. Ввод буквы в группе возможен и латиницей, и кириллицей. Ставить дефисы (А-09-23) необязательно (А0923).

**Пример:**

```bash
./script1.sh -f -r a0923 a0623 a0620
```

**Вывод:**

```
==== Студенты, чьи ФИО не соответствуют формату ФамилияИО ====
TretyakovAlO A-06-20
RybakovArV A-06-20
LevshchanovB A-09-23
KhizhniakovVlS A-06-23
DavydovAlD A-06-20
```

В команде (2) если количество попыток сдачи теста у студентов одинаковое, то выводятся они в алфавитном порядке. Ключ `-r` — в обратном порядке.

**Пример:**

```bash
./script2.sh A0923 пересдачеведение/tests/TEST-2
```

**Вывод:**


В команде (3) если под ввод пользователя подходит сразу несколько студентов, то предлагается выбрать одного из них, либо же ввести новое имя.

**Пример 1:**

```bash

```
